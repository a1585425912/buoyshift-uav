## 解释规则

正 gap 表示期望中的前一种方法更强；负 gap 表示顺序反转。接近 0 dB 的 gap 需结合同 seed 配对支持率判断是否只是 Monte Carlo 抖动。完整数值与配对支持率见 ordering CSV。

## 主要异常趋势

### 节点数

- N=20：Cluster-KF-DPC 为 -3.355 dB，KF-DPC 为 -0.094 dB，差 -3.261 dB。
- N=1000：Cluster-KF-DPC 为 -0.494 dB，KF-DPC 为 -0.095 dB，差 -0.399 dB。
- N=2000：差距缩小到 -0.188 dB，但仍未反转为正。
- Cluster 分支节点 RMSE 随簇规模增大而下降：N=20 为 8.111 m，N=500 为 2.506 m，
  N=1000 为 1.629 m，N=2000 为 1.194 m；普通节点 KF 约为 0.53–0.54 m。

### 连通性

Cluster-KF-DPC 相对 KF-DPC 的差值在所有连通性点均为负，约 -0.46 至 -0.33 dB，
且随 p 增大没有恢复预期顺序。这表明当前主要瓶颈不是通信图连通度，而是 cluster 节点
伪观测的滤波路径。

## 代码层只读诊断

### P1：cluster 伪观测自印证并造成协方差过度收缩

1. `ClusterTrajectoryLocalizer.update()` 在簇大小小于 2 时跳过处理，返回原节点状态；
2. `experiment.py` 不区分该返回值是否含有 peer 信息，仍调用
   `node_kf_prior.update_position_measurement(...)`；
3. 单节点簇的伪观测等于 KF 自身状态，创新为 0，但 Kalman 更新仍缩小协方差；
4. 重复执行后，滤波器把自己的预测反复当作独立证据，逐渐过度自信并降低原始观测权重。

默认 `n_clusters=40`，所以 N=20 时 20 个簇全为单节点簇，N=30 时也没有真正的 peer
信息，却仍执行上述自更新。这与 N=20/30 下约 8.1–8.2 m 的 Cluster 节点 RMSE 一致。
簇较大时，连续回灌的共识仍由相关的 KF 状态构造，但固定 `R=0.2²I` 把它当成每步独立
测量，也会造成共同误差累积。

运行证据（N=1000、p=0.03、20 MHz，20 trial 均值）：Cluster 节点 RMSE 从 block 0 的
0.435 m 连续上升到 block 7 的 1.699 m；普通节点 KF 从 0.664 m 收敛到 0.537 m。
Cluster-KF-DPC 功率同时从 -0.065 dB 恶化到 -0.530 dB，而 KF-DPC 从 -0.129 dB改善到
-0.094 dB。

### 验证缺口

现有 cluster 单元测试验证了单步几何误差下降和数值有限性，但没有覆盖：

- 单节点簇不应缩小 KF 协方差；
- 同一 cluster 伪观测反复回灌时协方差不得虚假坍缩；
- 多 block 条件下 Cluster 节点 RMSE 不应持续发散；
- Cluster-KF-DPC 相对 KF-DPC 的最低性能契约。

## 修复 Gate 建议

建议按 **Local Fix Only** 处理，不需要重写架构：

1. 对没有有效 peer 观测的节点跳过 cluster 伪观测更新；
2. 为 cluster 伪观测返回有效观测者数量/样本方差，并按簇大小、创新和相关性设置 R，
   不再对所有节点固定使用 0.2 m；
3. 先增加 singleton 与多 block 回归测试，修复后再重跑同口径 31 点 sweep。
