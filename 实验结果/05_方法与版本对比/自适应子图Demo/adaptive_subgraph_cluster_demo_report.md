## Demo 流程

1. 使用现有通信图的多源 BFS 将网络划分为通信子图；
2. 对目标节点 i，只允许同一子图内、与 i 有直接通信边的节点 j 提供相对位置观测；
3. peer 使用自己的节点 KF 状态和相对测量形成目标估计；
4. 根据子图混合权重汇总直接 peer 的估计；
5. 根据节点 KF 先验方差与 cluster 估计方差计算每节点、每时刻自适应融合系数；
6. 修正后的节点位置与修复后的 UAV KF-DPC 位置共同计算最终相位补偿。

## 自适应系数

对目标节点 i，设节点 KF 先验位置方差为 P_i，通信子图给出的定位方差为 R_c,i：

α_i = clip(P_i / (P_i + R_c,i), α_min, α_max)

其中 R_c,i 包含：

- peer 节点 KF 的位置方差；
- 相对位置测量噪声；
- 子图混合权重对应的有效 peer 数 n_eff = 1 / Σ w²；
- 不同 peer 对目标节点估计的实际离散度。

无直接 peer 时 α_i=0，节点保持自己的 KF 状态，不发生自印证更新。默认上限为 0.95，
旧固定模式仍可通过 `cluster_alpha_mode=fixed` 使用。

## 端到端 Demo

口径：N=1000、p=0.03、20 MHz、40 个子图、T_long=8、K=30、5 次 Monte Carlo，
固定组和自适应组使用相同 seed；两组都使用 v1.1.1 的 DPC 伪观测与保守协方差共识修复。

| 指标 | 固定 α=0.8 | 自适应 | 变化 |
|---|---:|---:|---:|
| Cluster-KF-DPC 功率 | -0.0634 dB | -0.0517 dB | +0.0117 dB |
| Cluster-DPC 功率 | -0.0692 dB | -0.0575 dB | +0.0117 dB |
| Cluster 节点 RMSE | 0.4285 m | 0.3762 m | -0.0523 m |
| UAV KF RMSE | 0.0299 m | 0.0299 m | 不变 |
| 融合系数均值 | 0.800 | 0.421 | 自适应 |
| 融合系数节点范围 | 0.800 | 0.176–0.881 | 自适应 |
| 平均有效 peer 数 | 2.47 | 2.47 | 图结构相同 |

Demo 的最终方法顺序为：

`Cluster-KF-DPC > Cluster-DPC > KF-DPC > DPC > Random`

## 当前限制

现有通信图由随机无向图加 ring backbone 生成，并不是根据节点欧氏距离构造的几何图。
本 Demo 将“通信边”解释为位于可通信/可相对定位范围内。如果下一步需要显式半径 r，应该把
场景图改成距离门限图或随机几何图，再比较半径、簇数和连通性；本次没有扩大到该建模变化。
