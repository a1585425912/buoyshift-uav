# 实验结果归档

本目录整理了通信子图聚类分支当前已经完成的实验结果，归档日期为 2026-08-25。

## 目录说明

- `00_统一数据表`：全部实验的标准化 Excel/CSV 总表，以及各次实验的独立 CSV。
- `01_节点数实验`：受控节点数、非受限节点数和早期子图节点数 Sweep。
- `02_连通度实验`：受控连通度、收敛速度分析和早期子图连通度 Sweep。
- `03_频率实验`：子图频率 Sweep，以及 v1.1.0/v1.1.1 的历史频率验证。
- `04_联合分析`：150 MHz 资源缩放实验，以及节点数、连通度、频率三因素联合网格。
- `05_方法与版本对比`：自适应子图 Demo、v1.1.1 与 main 的完整 Sweep 和差异分析。

## 指标口径

统一数据表的核心字段为：方法、功率指标、相位误差 RMSE、无人机位置 RMSE、节点位置 RMSE。

- 节点数实验的功率指标采用相对平均单节点理想发射功率的增益：
  `10 log10(P / P_single,mean)`，单位为 dB。
- 其他实验采用相对同一阵列理想相干发射功率的归一化功率：
  `10 log10(P / P_ideal)`，其中理想最佳为 0 dB。
- 相位误差为极性选择后折叠到 `[-90°, 90°)` 的尾段 RMSE。
- 空白单元格表示源实验没有导出该指标，或该基线方法不定义对应的位置误差；具体原因见统一数据表的“数据说明”列。

## 数据完整性

- 标准化总表包含 13 次独立运行、1163 条“实验点 × 方法”记录。
- 早期两次完整三类 Sweep 没有保存节点数实验的单节点增益，因此相关功率字段保持为空，没有用阵列归一化功率替代。
- 自适应子图 Demo 的原始汇总表没有导出尾段相位 RMSE，因此相关字段保持为空。

## 仓库体积控制

本目录保留论文分析所需的汇总表、关键趋势图和报告。逐点运行目录、缓存预览、时间序列大表和蒙特卡洛诊断中间文件没有提交；这些数据可通过仓库中的 Sweep 脚本重新生成。
