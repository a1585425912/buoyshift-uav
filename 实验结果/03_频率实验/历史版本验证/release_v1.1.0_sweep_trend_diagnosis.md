# v1.1.0-math-fixes 频率 sweep 趋势与回归诊断

## 结论

本次用 Release 标签 `v1.1.0-math-fixes`（提交 `e036a8b`）实际完成了 30–300 MHz、7 个频点、每点 20 次 Monte Carlo 的 sweep（N=1000、T_long=8、K=30）。

曲线没有大于 0.5 dB 的相邻频率回升，也没有 NaN/Inf 或块级冻结；但发现了一个 **P1 核心行为回归**：Release 当前代码的 KF-DPC 在 30 MHz 即退化到随机相位底线，UAV RMSE 从修复前约 0.03 m 上升到 26 m 以上。仅旁路新增的协方差共识后，指标恢复到修复前水平。因此，Release 内入库的漂亮 KF 曲线是父提交 `d2600aa` 生成的旧结果，不能代表 Release 当前代码。

## 代码判断

`experiment.py` 新增的 `consensus_covariance()` 使用

`P_i^+ = Σ_j w_ij² P_j`

它只在各节点估计误差相互独立时成立。当前节点反复使用共同真值驱动的观测、DPC 伪观测并多次交换状态，节点误差已经相关；正确协方差还需要 `Σ_j Σ_k w_ij w_ik P_jk` 中的交叉协方差。实现忽略交叉项，并在每个短步及长块反复调用，导致 P 被持续压小，KF 过度自信，后续观测几乎失去权重，最终产生 26 m 级 UAV 偏差。

## 测试缺口

Release 的 34 个测试全部通过，但测试只验证了“独立节点”假设下的二节点公式，端到端测试仅使用 N=20、K=2，并只检查有限值与较弱的速度误差条件。它没有锁定论文规模下 KF-DPC 应优于 DPC，也没有给 UAV RMSE 设置上限，因此未捕获该 P1 回归。

## Gate 建议

建议按 **Local Fix Only** 处理：先撤销或保守替代三处协方差共识赋值；在没有维护跨节点交叉协方差前，不应使用独立性公式反复收缩 P。修复必须新增论文规模的回归门槛：至少在 30 MHz、N=1000、T_long=8、K=30、固定 3 seeds 下，KF-DPC 应优于 DPC且 KF UAV 尾段 RMSE 不应超过 1 m。随后必须重跑并替换 Release 内全部结果与 `RESULTS.md`。

本报告为只读诊断，没有修改 Release 源码。
